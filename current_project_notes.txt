## 1. Implementation Progress
- Single cyberneuron matches the 2009 paper: per-input substitution tables, sum, four confidence bands, sequential/random ±1 teaching.
- `CyberTree` grows a two-layer network: joint lookup detectors on bit tuples, then a root joint table on the detector bits. Wiring is kept only when Polikarpov's PROP score rises.
- `CyberNeuron.signal()` is the legal value to pass into another neuron (confidence ordinal 0..3). `teach(..., learningDivider)` is the paper's learning coefficient k = 1/divider.
- Flat additive neurons are covered by tests that XOR and OR-of-ANDs do not become separable. The tree tests cover XOR, OR-of-ANDs, XOR-of-ANDs, and 3-bit parity.
- Public types and methods have Javadoc for the recognition bands, teaching divider, wire symbol, graph links, and tree growth. Checkstyle reports no Javadoc gaps.
- README describes the single-neuron scale, graph wires, and the `CyberTree.grow` steps.

## 2. Architecture & Technical Discoveries
- Output is `sum_i sbox_i[input_i]`. There is no activation and no multiplication. One neuron is a sum of independent lookups, i.e. a generalized additive model on discrete symbols.
- Cross-input logic (XOR, parity, OR of ANDs) does not fit in one additive neuron. It fits when several bits are packed into one table index (a joint lookup), which is what the later cyberneuron-tree paper grows.
- Authors explicitly reject backpropagation for a net of cyberneurons (arxiv 0907.0229 conclusion, and the KDD cyberneuron-tree paper). The index selection is not differentiable: inside a cell the gradient is 0, on the boundary it is a jump.
- The only local gradient that exists is ∂sum/∂activeCell = 1. That is exactly what `teach` already applies. It dies at the next lookup, so hidden layers cannot be trained by chaining that derivative.
- Published training is forward growth: add one substitution table, try connections, rewrite the table, keep the wiring that improves PROP = (k*TP + TN) / (k*TP + TN + k*FP + FN), k = N0/N1.
- Follow-up paper: Polikarpov, "Исследование новой модели искусственного нейрона как элемента системы обнаружения сетевых атак" (cyberneuron tree on KDD cup'99). Same author states backprop does not apply.
- Between neurons the wire must carry a symbol inside the next table, not the raw sum. `CyberNet.activate` still forwards the raw sum. `testNet_3_2` only checks the output count; sums can fall outside `0..maxInputValue` and then `calc` rejects them.
- Joint-table cells with conflicting labels are written once, by majority, through the existing YES teach. Unanimous cells are the one-step case from the paper.

## 3. Technical Debt & Refactoring
- `CyberNet.makeCopy` copies every entity twice and can disagree with `put` about input/output counts. Not used by the tree.
- `CyberNet.activate` has no symbol contract on neuron-to-neuron links. A later change should pass `signal()` (or another explicit quantizer) into the next table.
- Tree search enumerates bit tuples up to arity 12 and 100_000 combinations. It does not yet do the paper's per-bit evolutionary attach for wide non-binary features.
- Depth is two layers (detectors, then root). A deeper tree would treat the root signal as one more bit and grow again. Not implemented.
- `LearnStrategy` draws `RANDOM` from a shared `java.util.Random`. Sequential teaching is the deterministic one.

## 4. Current Work In Progress
- Multilayer question is answered by `CyberTree`, not by backpropagation.
- No open edit in progress.

## 5. Known Issues & Limitations
- A cyberneuron with separate binary inputs cannot represent XOR or `(a AND b) OR (c AND d)`, for any table contents.
- Pair tables cannot solve 3-bit parity, because every pair is tied against the third bit. A 3-bit joint table can.
- Alphabet on the input layer is what creates capacity. Quantizing every wire to 4 confidence levels throws that capacity away; keep wide symbols on the first tables.
- `teach` uses the full gap when `learningDivider` is 1. The paper's experiments prefer divider 4 (k = 0.25).

## 6. Open Questions & Pending Decisions
- Whether `CyberNet.activate` should start emitting `signal()` on neuron-to-neuron edges. That changes the 3-2 graph's numeric outputs.
- Whether the next step is deeper than two layers, or n-tuple tables over bytes (the virus-scanner setting) rather than over bits.

## 8. User Advice and Recommendations
- User wants a network and was considering backpropagation. Do not add gradient backprop through table indexes. Extend `CyberTree` (joint tables + PROP growth) or pass `signal()` into a downstream neuron whose `maxInputValue` is at least 3.
